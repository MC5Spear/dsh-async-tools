## 一、验证缺口与外部事项

2026-11-02 轮已取得并登记：隔离 rc.5 实例（复制式 profile）真实浏览器盲测——设置表单 20 字段与「适用预设」绑定块的渲染、目录六条目、勾选交互、刷新零副作用、恢复默认、窄屏 390×844 与标签可点均 PASS（截图存 `.local/tmp/bt9-blind/`，随仓不分发）；保存持久化在该部署形态被宿主拒绝写入（纯数值字段同拒，判别性证明与绑定块无关），失败路径（报错文案＋草稿保留＋重载回滚）诚实呈现。仍需完成：

- 预设绑定块的保存持久化在**官方 tgz 可写实例**上的复验（勾选保存、重载保持、空名单保存、恢复默认后 unset）；复制式 profile 的宿主写入限制是已知环境边界，不视为插件缺陷。
- 本轮三项修复与绑定名单的实际运行验证（真实模型端到端）；新反例须能检出对应退化，已有通过记录不覆盖修改后的实现。

### COMPAT-01：隔离安装的依赖来源与运行时同源尚未证明

新建正常根 Include 形态的隔离实例后，从已安装插件入口进行静态解析，仍有 DSH peer 落入祖先目录的 rc.4，配套 peer 另有其他宿主来源。本轮已验证官方安装、RPC 设置接口和预设创建可用；这些结果不能证明运行时实际取得了同版本同来源的依赖。

- **完成条件**：建立不继承工作区祖先依赖的隔离安装环境，核对插件运行时实际取得的九项 DSH peer、配套及直接依赖，满足[需求 7.3](<requirements.md#73-当前兼容基准与统一维护>)。在该环境复核官方装载、预设、设置和受影响行为；静态包清单或 `createRequire` 单项结果不代替运行期证据。四个受支持宿主分别保留自己的证据范围。

### RC5-01：四宿主远端 CI 结果与发布授权

[CI 配置](<../.github/workflows/ci.yml>)包含 rc.2、rc.3、rc.4、rc.5；当前修订尚无对应远端 Actions 实跑结论。

### MIGRATE-01：既有部署的旧平铺配置需要迁移确认

仓内已有平铺配置装载警告及迁移说明；既有部署是否仍使用旧平铺形态，本轮没有读取私有部署配置，也没有代为修改。旧配置可能正常装载却回落默认值。

- **完成条件**：部署负责人升级前按[更新日志的迁移说明](<../CHANGELOG.md>)检查旧 `config`，必要时改为 `config.settings`，并确认实际生效值。该事项不授权开发任务修改在用实例；迁移说明和警告的仓内修正继续由本仓维护。

### CLEANUP-01：旧验证资源归属尚未确认

旧隔离实例、浏览器和测试 home 的归属记录本轮未核实。当前新建的验收实例（bt9）已停止，不能据此宣称旧资源全部清理。
