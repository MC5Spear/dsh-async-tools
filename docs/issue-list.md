## 一、非阻断问题

### DOC-SHELL-01：跨平台执行器与固定 PowerShell 指引不一致

- **出现概率：低；严重程度：中；不阻断推送。** 当前使用说明面向 Windows，Linux 尚未验证；如果在 Linux 的 bash 执行器组合中使用，固定 PowerShell 指引会误导语法。
- [模型描述与命令参数](<../lib/text.js#L36-L61>)固定写 PowerShell，[防护纪律注入](<../lib/host.js#L126-L137>)也未按执行器区分。需求保留 Linux 验证目标，不能用当前 Windows 结果宣称跨平台通过。
- **完成条件：** 按实际执行器或平台生成准确描述和防护前提，并在 Linux 验证；若改变平台目标，须另有明确决定。

### ASK-DUPLICATE-01：非标准多选载荷可重复同一标签

- **出现概率：低；严重程度：低；不阻断推送。** 正常客户端使用集合维护选择，重复标签需要非标准或损坏的公开接口载荷。当前需求未明确重复标签处理，此项是增强建议，不作为已证需求违背。
- [作答校验](<../lib/ask-takeover.js#L420-L440>)接受 `selected: ['A', 'A']`，并在[答案构造](<../lib/ask-takeover.js#L372-L374>)中原样保留。没有证据表明造成选择越权、伪造未选项或任务中断。
- **处理条件：** 后续可拒绝重复标签或按集合去重，并使界面回执、工具返回和迟到通知保持一致；不因此扩充当前必交付范围。
