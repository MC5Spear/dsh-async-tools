## 一、发布验证缺口

### VERIFY-01：受影响行为、真实模型及界面证据尚不完整

- 本轮缺陷修正的受控回归（含认领生命周期、读取失败注记、条目上限、回滚凭据、会话遮蔽与出口注记两分）与 rc.2/rc.5 双锚点全量套件已通过；仍需对应的实际运行证据及能检出退化的反例。真实命令、单次审批、用户插话与排队、取消、并发等待及交付竞态、编排 PTC 钩子、实时模型策略在恢复会话和多层子代理中的行为，以及 Windows 上的插件装卸与 owner 作业生命周期，尚缺本轮完整实例证据；已有受控回归通过不能替代这些路径。
- 绑定名单的官方可写实例 GUI 保存、重载保持、空名单、恢复默认 unset、升级保留和重启持久化尚未完整核验。本轮独立临时实例的设置 RPC 已有部分正向证据，但不等于 GUI 或兼容同源通过。
- 本轮浏览器可启动，但探针未成功定位插件详情，未取得可判定的设置页截图；不是已证实的插件页面故障，也不能登记视觉通过。此前复制式 profile 的局部截图结论保留其原始范围，不推广到当前候选全部行为。
- 待答多行输入的两种位置、深浅主题、窄屏、明显选中反馈、键盘、中文输入法确认、真实读屏及触屏软键盘仍缺完整证据。设置表单还需核对官方字段尺寸、主题别名的实际取值、帮助和错误关联，以及审批界面的实际操作。真实模型等待必要性、父子协作续接及直接交付对照尚未完成；对照须记录模型请求数和可取得的输入、缓存命中及输出用量。
- Linux 命令、单次提权及卸载生命周期仍需对应环境；Windows 或替身不代替 Linux。
- 结算通知与注册表状态滞后的自然时序，以及主体最后领取后进入空闲的完成消息恢复路径，尚无可确认的实例级结论；受控推演不升级为已证实缺陷。
- 当前 rc.5 不允许后台子代理直接请求人类交互；该适用边界不要求插件绕过宿主限制，相邻消息路径不代替目标提问通知的证明。

### COMPAT-01：当前隔离安装仍未证明运行时同版本同来源

本轮官方 tgz 安装及启动成功，但从已安装插件入口静态解析，九项 DSH peer 仍落入工作区祖先的 rc.4 依赖，配套 peer 另有其他宿主来源。该 home 位于工作区内，结果说明测试布局受到祖先搜索影响，不证明所有官方部署都会混用，也不满足当前 rc.5 同源要求。

**完成条件**：建立不继承工作区祖先依赖的隔离安装，按[需求 7.3](<requirements.md#73-当前兼容基准与统一维护>)核对运行时实际取得的九项 DSH peer、配套及直接依赖。在该环境核验官方装载、预设、设置与受影响行为；静态包清单和单次 `createRequire` 不代替运行期证据。四个受支持宿主分别保留证据边界，不修改宿主源码或用版本豁免代替兼容。

### RC5-01：当前修订的四宿主远端 CI 尚无结果

[CI](<../.github/workflows/ci.yml>)配置包含 rc.2、rc.3、rc.4、rc.5，但当前候选没有对应远端 Actions 实跑结论。本地检查或矩阵配置存在不等于远端已通过；取得推送授权后核对四档结果和集合外拒载。标签与 Release 仍需单独发布授权。

## 二、部署与资源负责人待确认事项

### MIGRATE-01：旧平铺配置的实际迁移状态

仓内已有装载警告及[迁移说明](<../CHANGELOG.md#从-025-形态的行配置迁移>)；本轮未读取或修改私有在用配置。部署负责人升级前核对旧 `config` 是否需要改为 `config.settings`，并确认实际生效值。该交接不代表本仓缺少迁移说明，也不授权修改在用实例。

### CLEANUP-01：旧验证资源的归属

本轮自建资源与历史资源分别处理。本轮资源停止不能证明旧实例、浏览器或测试 home 全部清理。维护者应向原创建者确认归属及使用方，只处理可确认属于验证且不再使用的资源；归属不明时保留，不按端口批量终止，不在公开清单保存机器标识或凭据。
