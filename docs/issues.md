# 已知问题与验证缺口（DSH 0.2.1 兼容线）

## 适用版本与状态

本清单适用于 `0.2.9-alpha.5+dsh.0.2.1-rc`，沿用 alpha.4（`02dd6e52665b8ebdce1571a25e88587f28c16341`）的运行代码与宿主准入。精确宿主为 `0.2.1-rc.2`、`0.2.1-rc.3`、`0.2.1-rc.4`、`0.2.1-rc.5`。本版只更新用户资料和包版本，尚未通过稳定验收。

本文件是对应分支的公开产品问题正文，供使用者判断影响、维护者继续处理。应在安装所用的准确提交下阅读清单，不以移动分支的最新状态代替旧版本结论。需求与机制分别见匹配版本源码中的 `docs/requirements.md` 和 `docs/design.md`，操作与临时处置见[用户参考](<user-reference.md>)。另一兼容线的结果不能自动作为本线通过依据。

概率／严重程度分别评为高、中、低；任一高或同项双中阻断稳定晋级，其他问题仍登记处理。必要验证未完成不能宣布稳定验收通过。一般缺陷和验证缺口不自动阻断完成验收后的 alpha 推送；已确认的严重秘密泄漏、未经授权执行、重大数据破坏风险，或未妥善处理的有效凭据泄漏会暂停受影响内容公开；普通本机路径、私有链接等先清理并核对，不将它们视为产品安全故障。不得将安全尚未全部测完直接称为发现严重安全问题。

本清单区分确认缺陷、验证缺口和可选建议。已有证据只在代码、精确宿主、配置与方法未受影响时复用；未在本次重新核验的存量项不算新验证通过。已核实修复的旧症状不再保留为当前问题，修订历史由 Git 保存。

## 一、稳定晋级判断

当前仍有确认缺陷与必要验证缺口，不能晋级稳定版本。长编号恢复指引和调用示例转义已修订；条目结转的完成消息路径与首次等待直付路径分别判断，不将局部修复视为共同输入额度全部达标。

## 二、其他实现与文档问题

| 标识 | 概率／严重 | 当前差距与完成条件 |
| --- | --- | --- |
| WAIT-F02 | 低／低 | 零等待的子代理目录查询悬置时，用户插话未及时结束检查，约一秒后仍以 `unconfirmed` 返回；消息未删除。须让准备查询与有效插话竞速，并报告真实结束原因。 |
| WAIT-F03 | 低／中 | 混合目标的子代理目录在检查窗口内未答复时，即使作业已确认运行或有就绪结果，等待也可能整体以 `unconfirmed` 提前返回。可先只指定已确认的作业，再重查子代理关系，不重跑作业。须报告已就绪内容，剩余时间内继续等待已确认工作，其他目标保持未知。 |
| WAIT-READ-DEADLINE-01 | 低／中 | 等待已到截止或已被插话打断后，若仍要从隐藏的原生读取入口补取结果，等待可能继续卡在该读取上。此处指出代码的未限时路径，真实宿主慢读取的可达和耗时仍待实测。长时间无响应时先保留编号和实际状态，勿重跑原作业。须让零等待和正等待都遵守总截止及取消，并保留后续读取机会。 |
| WAIT-STEER-PREP-01 | 低／中 | 正等待的准备阶段，子代理目录尚未返回时，先收到目标普通转达、再收到用户插话，等待可能没有及时按插话结束。插话仍在会话，并非被删除。须分别观察两类消息，让后来到达的插话及时交回，不改变后台任务状态。 |

| WAIT-F04 | 低／低 | 注册拒绝的多行原错虽已在模型与 stderr 中处理，仍原样进入 `logger.warn`，可能混淆日志行。须统一单行化；未证明秘密泄漏或越权。 |
| WAIT-ITEMS-01 | 低／中 | 完成消息的未领取条目结转已实现，但首次等待直付仍有残余：同一输入窗口已有 10 条结果后，后续命令或编排在首次等待内完成时，零字符份额未被识别为条目已满，仍可返回额外的完成／终止条目；空结果还会记为已交付，而不是整条延后。未证同一正文重复或永久丢失。须使两类首次等待的真实返回也遵守共同输入的 10 条上限，覆盖空正文、非零退出、终止和非空正文，超额项保留可续取路径。按已收到的结局处理，不重跑原作业；`maxResultChars` 不能作为状态和诊断的总量保证。 |
| WAIT-ID-BOUND-01 | 低／中 | 等待及首次等待的附带条目虽已裁短状态行，文本渲染又在分隔标题或目标行中插入完整原始编号。合法的超长 `jobKind` 或外来作业编号可使预算外标识随编号长度增长；调用示例已正确转义，这不是同一个缺陷。通常保持简短的作业类型标识；遇到长编号时保留原值，不自行截短后调用。须约束模型可见标识的总量并保留准确编号的恢复入口，不改坏结构化 ID 或限制合法配置。 |
| N-CFG-01 | 低／低 | 其他插件含同名 `settings` 键时，全树监听可能误登记本包配置降级。须核实行归属，不只按子树键判断。未观察到外来配置被修改，上一合法值仍保留。 |
| SF-01 | 中／低 | 静默诊断额外排除退出码 0，而需求 6.3 无此例外。须恢复现行要求的条件提示；只有拟保留例外并改变要求时才需另行批准，设计与实现一致不能代替批准。 |
