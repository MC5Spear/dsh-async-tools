# 已知问题与验证缺口（DSH 0.2.2 兼容线）

## 适用版本与状态

本清单适用于 `0.2.10-alpha.2+dsh.0.2.2`，本轮代码候选为 `204e89a9390b8c91275f33d9a1963c35ccccca79`，精确宿主为 `0.2.2-rc.1`。本轮核对交付额度记账、长作业编号的恢复指引及相关文案；真实模型、完整安装维护和设备验证仍有缺口，未通过稳定验收。最终候选还包含用户文档与 alpha 标识调整。

本文件是对应分支的公开产品问题正文，供使用者判断影响、维护者继续处理。应在安装所用的准确提交下阅读清单，不以移动分支的最新状态代替旧版本结论。需求与机制分别见匹配版本源码中的 `docs/requirements.md` 和 `docs/design.md`，操作与临时处置见[用户参考](<user-reference.md>)。另一兼容线的结果不能自动作为本线通过依据。

概率／严重程度分别评为高、中、低；任一高或同项双中阻断稳定晋级，其他问题仍登记处理。必要验证未完成不能宣布稳定验收通过。一般缺陷和验证缺口不自动阻断完成验收后的 alpha 推送；已确认的严重秘密泄漏、未经授权执行、重大数据破坏风险，以及待推送内容或历史中的不宜公开材料会阻断 alpha。不得将安全尚未全部测完直接称为发现严重安全问题。

本清单区分确认缺陷、验证缺口和可选建议。已有证据只在代码、精确宿主、配置与方法未受影响时复用；未在本次重新核验的存量项不算新验证通过。已核实修复的旧症状不再保留为当前问题，修订历史由 Git 保存。

## 一、稳定晋级判断

当前版本测试存在高概率失败项，另有条目配额、恢复指引及必要验证缺口，不能晋级稳定版本。测试维护问题、业务缺陷和未验证内容分别登记，不把未验当作故障，也不把受控预算锚通过当作全部通过。
