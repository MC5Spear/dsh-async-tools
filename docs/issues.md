# 已知问题与验证缺口（DSH 0.2.2 兼容线）

## 适用版本与状态

本清单适用于 `0.2.11-alpha.1+dsh.0.2.2`，验收运行代码基线为 `533b371c9f3cecc3dc3f86b73c25a3216c23da8c`。同一安装件准入 DSH `0.2.2-rc.1`、`0.2.2-rc.2` 和 `0.2.2-rc.3`。本线只有 `adapt/dsh-0.2.2-alpha` 试用渠道，尚未通过稳定验收；稳定晋级还须实际使用体验和明确确认。

本文件是对应分支的公开产品问题正文，供使用者判断影响、维护者继续处理。应在安装所用的准确提交下阅读清单，不以移动分支的最新状态代替旧版本结论。需求与机制分别见匹配版本源码中的 `docs/requirements.md` 和 `docs/design.md`，操作与临时处置见[用户参考](<user-reference.md>)。另一兼容线的结果不能自动作为本线通过依据。

概率／严重程度分别评为高、中、低；任一高或同项双中阻断稳定晋级，其他问题仍登记处理。必要验证未完成不能宣布稳定验收通过。一般缺陷和验证缺口不自动阻断完成验收后的 alpha 推送；已确认的严重秘密泄漏、未经授权执行、重大数据破坏风险，或未妥善处理的有效凭据泄漏会暂停受影响内容公开；普通本机路径、私有链接等先清理并核对，不将它们视为产品安全故障。不得将安全尚未全部测完直接称为发现严重安全问题。

本清单区分确认缺陷、验证缺口和可选建议。已有证据只在代码、精确宿主、配置与方法未受影响时复用；未在本次重新核验的存量项不算新验证通过。已核实修复的旧症状不再保留为当前问题，修订历史由 Git 保存。

## 一、稳定晋级判断

三版同包可用于 alpha 试用；直接子代理关系、等待截止处理和部分运行提示仍有缺陷。真实模型输入、部分宿主取消与审批、使用方式及恢复等必要验证未完成，不能晋级稳定版本。
