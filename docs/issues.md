# 已知问题与验证缺口（DSH 0.2.1 兼容线）

## 适用版本与状态

本清单以 2026-11-16 上一轮验收为基线：交验提交 `8b86714fa6561c5b6ca5ae83e8d5c938da390cec`，包版本 `0.2.9+dsh.0.2.1-rc`，精确宿主为 0.2.1-rc.2、0.2.1-rc.3、0.2.1-rc.4、0.2.1-rc.5。该基线未通过稳定发布验收。当前工作树的改动及本次清单整理均未重新完成产品验收，不能据此推断下列问题已修复。

本文件是对应分支的公开产品问题正文，供使用者判断影响、维护者继续处理。应在安装所用的准确提交下阅读清单，不以移动分支的最新状态代替旧版本结论。需求与机制分别见匹配版本源码中的 `docs/requirements.md` 和 `docs/design.md`，操作与临时处置见[用户参考](<user-reference.md>)。另一兼容线的结果不能自动作为本线通过依据。

概率／严重程度分别评为高、中、低；任一高或同项双中阻断稳定晋级，其他问题仍登记处理。必要验证未完成不能宣布稳定验收通过。一般缺陷和验证缺口不自动阻断完成验收后的 alpha 推送；已确认的严重秘密泄漏、未经授权执行、重大数据破坏风险，以及待推送内容或历史中的不宜公开材料会阻断 alpha。不得将安全尚未全部测完直接称为发现严重安全问题。

上一轮两语用户资料的对应修订已通过内容复核与独立审读，实际包与该修订一致；这不关闭运行帮助、实现、维护注释或实机验证问题。已确认修复的旧症状不重复列为开放项，修订历史由 Git 保存。

| 标识 | 概率／严重 | 影响、触发条件与完成条件 |

| AG-01 | 中／高 | 委托创建未读取并传入宿主生效的内部深度上限。官方 0.2.1-rc.5 与 0.2.2-rc.1 的受控黑盒验证表明，宿主设置禁止委托时，当前调用仍到达创建哨兵；未创建真实模型子代理，未证明无限递归、沙箱或审批逃逸。须按每次生效设置解析并传递上限，核实后端支持，验证零值／默认、根／深层、热变更、恢复会话及各精确宿主。0.2.1-rc.2–rc.4 目前仅静态同因，不算实测。 |
| WAIT-F01／COPY-C01／旧 U1 残余 | 中／中 | 延后结果的提示仍承诺下一批优先自动送达、无需专门领取，实际步骤监听只关旧批，不主动续投。没有新结算或本包调用时正文留在缓冲，可能导致结果遗漏和错误收尾。主动零等待可恢复，不是已证数据丢失。须统一机制与两语提示；没有自动续投时，明确额度重置后用零等待续取，不改变需求掩盖差距。 |

修复须保留安全合成反例、补受影响精确宿主回归并重新验收；已有开发完成声明不关闭条目。
